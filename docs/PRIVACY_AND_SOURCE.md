# Privacy and Source

## What this repository is

A portfolio showcase for a production website. It describes the engineering of the Kalendra landing page; it is not a source distribution.

## What is published

- Written descriptions of structure, design decisions and trade-offs
- Original diagrams created for this showcase
- Real screenshots of the public website, desktop and mobile

## What is intentionally not published

- Production source code, in whole or in part
- Build, hosting and deployment configuration
- Environment files and the identifiers used by the form service
- Community and social invitation links
- Version control history of the production repository
- Any visitor or sign-up data

## How the descriptions were produced

The site's source was inspected read-only and built in a separate scratch location, and the live site was loaded in a browser. Statements describe behaviour observed in code or on the live page. Marketing statements about the product are labelled as such and are not presented as implemented functionality. Diagram labels are conceptual.

## Images

Screenshots are captures of the public site. No form was submitted and no personal data appears in them. Images were re-encoded as WebP with metadata removed.

## Publication checks

Before publishing, every file was checked for source code, credentials, personal data, email addresses, local file-system paths and previous account references. None remain.

## Access

Source access for hiring or due-diligence purposes can be discussed at the owner's discretion.
